# Blu Raspberry and the Gosh Darnits website

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and the `assets` folder, keeping the same folder structure.
3. In repository Settings → Pages, choose Deploy from a branch, select `main` and `/(root)`, then save.

## Before launch
- Replace the `#` links in Listen Now with your streaming links.
- Add tour dates in the Tour section.
- The Store button already links to your Big Cartel shop.
- Connect the mailing list form to a mailing-list provider before collecting addresses.

The hero image is in `assets/hero.jpg`.
